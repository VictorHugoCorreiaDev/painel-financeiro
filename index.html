🔄 Sincronização entre dispositivos

Conecte um banco de dados gratuito (Firebase) pra você e sua esposa verem os mesmos lançamentos em tempo real, em qualquer aparelho. Como configurar
1. Acesse console.firebase.google.com e crie um projeto grátis (qualquer nome)
2. No menu, vá em Build → Firestore Database → Criar banco de dados (modo teste, região mais próxima ex: southamerica-east1)
3. Vá em ⚙️ Configurações do projeto → seus apps → clique no ícone </> (Web) → registre um app
4. Copie o objeto firebaseConfig que aparece (com apiKey, projectId etc.) e cole no campo abaixo
5. Combine com sua esposa um código da família (qualquer texto único, ex: "correia-financas-26") — os dois usam o mesmo código no app de cada um
